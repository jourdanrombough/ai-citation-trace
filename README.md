# How AI Search Chooses Its Sources

An interactive scrolling story that traces the eight stages AI search runs before it cites a page, from query fan-out and retrieval to reranking and the final citation. It includes a built-in citation simulator and a 90-day action plan for technical SEOs.

**Live demo:** https://jourdanrombough.github.io/ai-citation-trace/
**Published on:** https://optimizationtheory.com/ai-citation-trace/

## What it covers

- How a single prompt fans out into many background searches
- How AI systems retrieve, filter, rerank and choose which sources to cite
- A citation simulator that shows why some pages get cited and others don't
- A practical 90-day plan for earning AI search visibility (GEO / AEO)

## Built with

Single-file HTML, CSS and vanilla JavaScript with scroll-driven animation. No frameworks and no build step. Open `index.html` in a browser to run it locally.
